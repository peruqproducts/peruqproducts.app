# peruqproducts.app

Sitio web de Perú Q. Products.

- `index.html` — Landing page de exportación (página principal, orientada a nuevos leads en EE. UU.).
- `catalogo/index.html` — Catálogo de pedidos con carrito, para clientes existentes.
- `assets/images/` — Logo y fotos de operaciones.

## Pendiente por completar

En `index.html`, busca `TODO` y las etiquetas "Confirmar"/"Completar" para actualizar:
- Correo de contacto real (`CONTACT_EMAIL` en el `<script>` y los enlaces `mailto:`).
- Teléfono / WhatsApp.
- Ciudad de operaciones (si no es Lima).
